## ROAD 0.1.0 — первый публичный релиз

**Публикации по расписанию** для YouTube, TikTok и Instagram.

### Что умеет
- Отложенный постинг по расписанию
- Пакетная загрузка видео
- Несколько аккаунтов на площадку
- Работа в фоне и автозапуск с Windows
- Автообновления через GitHub Releases

### Установка
1. Скачайте `ROAD Setup 0.1.0.exe` ниже
2. Установите и активируйте лицензионный ключ
3. Подключите аккаунты в разделе «Аккаунты»
