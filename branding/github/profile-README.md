## Сейчас делаю

**[ROAD](https://github.com/1lyki02/AutoUploader)** — десктоп-приложение для публикаций по расписанию в YouTube, TikTok и Instagram.

Планируешь контент, загружаешь пакетом, назначаешь время — приложение публикует само, в фоне.
